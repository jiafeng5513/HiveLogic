## 核心脉络（一段话版）

从 DojoAgents 借鉴分析（第九节）得出核心诊断：**HiveLogic 的短板是数据工程而非数据源**——不需要完美数据源，需要"把混乱源头变成稳定资产"的管线。数据盘点（00）证实了这一诊断：同一能力存在 2-3 套并行实现。因此数据方向的工作性质是**收敛**：行情数据收敛为统一网关（01），新闻/搜索双管线收敛为统一存储+统一治理（02）。数据底座沉淀后，再依次展开 Agent 和 UI 方向。
